# Practical Mathematical Applications Using C Programming

This assignment focuses on applying basic mathematical concepts through C programming. It includes salary calculations, measurement conversions, percentage calculations, temperature conversion, and geometric formulas. It also explores variable manipulation to determine standard paper dimensions. These tasks develop a strong understanding of arithmetic operations and practical programming applications.

1. Salary Calculator:
   Calculates gross salary by adding basic salary, dearness allowance (DA), and house rent allowance (HRA).
2. Distance Converter:
   Converts a given distance in kilometers into meters, feet, inches, and centimeters.
3. Percentage Calculator:
   Calculates the total marks and percentage obtained in five subjects.
4. Temperature Converter:
   Converts temperature from Fahrenheit to Celsius using a mathematical formula.
5. Area and Perimeter Calculator:
   Calculates the area and perimeter of a rectangle and the area and circumference of a circle.
6. Paper Size Calculator:
   Determines paper dimensions from A0 to A8 by repeatedly swapping and halving length and width values.
